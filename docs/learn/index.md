# یادگیری: واژه‌نامه مفاهیم

این بخش مفاهیم فنی پروژه را به زبان ساده توضیح می‌دهد. برای مفاهیم مهم صفحه آموزشی جدا با مثال وجود دارد.

## صفحات آموزشی

مسیر پیشنهادی (به همین ترتیب):

1. [نمایه معکوس](inverted-index.md): چرا جست‌وجوی کلیدواژه‌ای سریع است
2. [BM25](bm25.md): رتبه‌بندی کلیدواژه‌ای، مقایسه با جست‌وجوی برداری، جست‌وجوی ترکیبی و RRF
3. [QMD](qmd.md): ترکیب همه این‌ها در یک موتور جست‌وجوی Markdown و اتصال به Hermes

## واژه‌نامه

| اصطلاح | توضیح کوتاه | بیشتر |
|---|---|---|
| **LLM** (مدل زبانی بزرگ) | مدلی که متن را می‌فهمد و تولید می‌کند؛ موتور استدلال دستیار | [نگهداری داده](../architecture/data-residency.md) |
| **Agent** | برنامه‌ای که با LLM تصمیم می‌گیرد چه ابزاری را با چه ترتیبی صدا بزند تا کاری انجام شود | [اتصال به سامانه‌ها](../architecture/integration.md) |
| **Hermes** | چارچوب Agent متن‌باز Nous Research؛ مهارت‌سازی از تجربه، MCP، مرورگر، زمان‌بندی | [محصولات مشابه](../research/landscape.md) |
| **MCP** (Model Context Protocol) | پروتکل استاندارد اتصال Agent به ابزارها و سامانه‌ها | [اتصال به سامانه‌ها](../architecture/integration.md) |
| **Browser-use** | کار Agent با مرورگر مثل یک کاربر، برای سامانه‌های بدون API | [اتصال به سامانه‌ها](../architecture/integration.md) |
| **RAG** | بازیابی تکه‌های مرتبط از اسناد و دادن آن‌ها به LLM برای پاسخ مستند | [دانش ترکیبی](../architecture/llm-wiki.md) |
| **LLM Wiki** | ویکی Markdown که Agent از روی اسناد می‌سازد و به‌روز نگه می‌دارد | [دانش ترکیبی](../architecture/llm-wiki.md) |
| **Embedding** | تبدیل متن به بردار عددی به‌طوری که متن‌های هم‌معنا بردارهای نزدیک داشته باشند | [BM25 در برابر برداری](bm25.md#bm25-vs-vector) |
| **جست‌وجوی برداری** | پیدا کردن متن‌های هم‌معنا با مقایسه Embeddingها | [BM25](bm25.md) |
| **BM25** | رتبه‌بندی سندها بر اساس کلمات مشترک با پرسش | [BM25](bm25.md) |
| **جست‌وجوی ترکیبی (Hybrid)** | ترکیب BM25 و جست‌وجوی برداری | [مثال VM-023](bm25.md#hybrid) |
| **RRF** | ادغام چند فهرست نتیجه بر اساس رتبه | [مثال عددی RRF](bm25.md#rrf) |
| **Reranker** (بازرتبه‌بند) | مدلی که نتایج اولیه را دقیق‌تر مرتب می‌کند | [BM25](bm25.md) |
| **تکه‌بندی (Chunking)** | شکستن سند به تکه‌های کوچک برای نمایه‌سازی؛ برای مقررات در سطح ماده و بند | [دانش حقوقی](../requirements/regulatory-knowledge.md) |
| **pgvector** | افزونه PostgreSQL برای ذخیره و جست‌وجوی بردار | [فناوری‌ها](../architecture/stack.md) |
| **QMD** | موتور جست‌وجوی ترکیبی محلی روی فایل‌های Markdown | [آموزش QMD](qmd.md) |
| **نمایه معکوس** | فهرست «کلمه ← سندها» که جست‌وجوی کلیدواژه‌ای را سریع می‌کند | [نمایه معکوس](inverted-index.md) |
| **شباهت کسینوسی** | معیار نزدیکی دو بردار؛ هرچه به ۱ نزدیک‌تر، هم‌معناتر | [QMD](qmd.md) |
| **گسترش پرسش** | تولید عبارت‌های جایگزین برای پرسش تا اسناد با واژگان متفاوت هم پیدا شوند | [QMD](qmd.md) |
| **HyDE** | ساخت پاسخ فرضی و جست‌وجوی اسناد واقعی شبیه به آن؛ فقط ابزار جست‌وجو، نه شاهد | [QMD](qmd.md) |
| **Collection / Context در QMD** | پوشه قابل جست‌وجو و توضیح زمینه‌ای که همراه نتایج برمی‌گردد | [QMD](qmd.md) |
| **گراف دانش** | شبکه موجودیت‌ها (نامه، قرارداد، تجهیز، شخص) و روابطشان | [گراف دانش](../architecture/knowledge-graph.md) |
| **GraphRAG** | RAG مبتنی بر گراف دانش و خلاصه جوامع آن؛ قدرتمند ولی پرهزینه | [فناوری‌ها](../architecture/stack.md) |
| **Honcho** | سرویس حافظه مکالمه‌ای برای Agent | [لایه‌های حافظه](../architecture/memory.md) |
| **منشأ (Provenance)** | ثبت اینکه هر داده یا ادعا از کدام سند و کدام نسخه آمده | [معماری دانش](../architecture/knowledge-architecture.md) |
| **OCR** | تبدیل تصویر متن (اسکن) به متن قابل جست‌وجو | [پیوست‌ها](../requirements/attachments.md) |
| **STT** | تبدیل گفتار به متن | [دستیار زنده](../requirements/live-copilot.md) |
| **Diarization** (تشخیص گوینده) | مشخص کردن اینکه هر جمله را چه کسی گفته | [دستیار زنده](../requirements/live-copilot.md) |
| **VAD** | تشخیص بخش‌های دارای گفتار در صوت | [دستیار زنده](../requirements/live-copilot.md) |
| **On-Premises** | اجرا و ذخیره داخل سازمان، نه در ابر | [نگهداری داده](../architecture/data-residency.md) |
| **دروازه LLM** | نقطه واحد عبور همه درخواست‌ها به مدل‌ها، برای جابه‌جایی مدل، لاگ و پنهان‌سازی داده | [نگهداری داده](../architecture/data-residency.md) |
| **Ragas** | ابزار سنجش کیفیت سیستم‌های RAG | [فناوری‌ها](../architecture/stack.md) |
