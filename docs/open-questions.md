# سؤالات باز

## پاسخ داده شده

- [x] **آیا دستیار اجازه اقدام دارد؟** فاز ۱ خیر، فقط خواندن، تحلیل، یادگیری و پیشنهاد. ثبت و ارجاع وظیفه در فاز بعد. ([فازبندی](requirements/phasing.md))
- [x] **کجا اجرا شود؟** فعلاً هیچ‌جا؛ مرحله تحقیقات. در نهایت در دیتاسنتر سازمان توسط پیمانکار.
- [x] **وضعیت سامانه‌ها؟** برخی وب‌سرویس دارند، برخی فقط رابط کاربری؛ نیاز به Browser-use و ساخت MCP از تجربه. ([اتصال به سامانه‌ها](architecture/integration.md))

- [x] **محل نگهداری داده؟** همه دانش و داده داخل سازمان؛ فقط استدلال LLM می‌تواند وب‌سرویس بیرونی باشد. ([نگهداری داده](architecture/data-residency.md))
- [x] **تعداد فازها؟** حدود پنج فاز. ([فازبندی](requirements/phasing.md))
- [x] **مصوبات شورا از کجا می‌رسند؟** از طرف شهرداری به‌صورت نامه در دبیرخانه سازمان، خطاب به معاونت یا مدیرعامل، و سپس ارجاع به مدیریت‌ها. ([مسیر ورود مقررات](requirements/regulatory-knowledge.md#ingestion-path))
- [x] **اساسنامه‌های سازمان‌ها و شرکت‌های وابسته؟** بعداً توسط ادمین از طریق رابط مدیریت دانش اضافه می‌شوند (REQ-17).

## باز
- [ ] تهیه مجموعه آزمون فارسی (پرسش‌های واقعی دفتر معاونت با پاسخ مرجع) برای ارزیابی Embedding، جست‌وجو و پاسخ‌ها.
- [ ] چه کسی صفحات مهم LLM Wiki را بازبینی می‌کند (مدیر دانش، واحد حقوقی برای صفحات مقرراتی)؟
- [ ] ویکی بر اساس چند سطح طبقه‌بندی جدا شود؟
- [ ] شرایط مجوز استفاده سازمانی Obsidian، یا استفاده از ویرایشگر Markdown دیگر.
- [ ] حجم تقریبی آرشیو مصوبات و بخشنامه‌های گذشته در دبیرخانه.

- [ ] فهرست دقیق سامانه‌های سازمان (دبیرخانه، نامه‌نگاری، CMMS، قراردادها، منابع انسانی، مالی، پروژه‌ها، انبار، تقویم) با نام نرم‌افزار، سازنده، نسخه، و نوع دسترسی (API، دیتابیس، فقط UI).
- [ ] تقویم سازمان روی چه بستری است؟
- [ ] موضوعات خلاصه خبری روزانه معاونت و منابع خبری مجاز.
- [ ] منابع سخت‌افزاری موجود در دیتاسنتر (GPU، سرور، ذخیره‌سازی) و بودجه خرید.
- [ ] انتخاب ارائه‌دهنده LLM بیرونی (با توجه به دسترس‌پذیری از ایران، تحریم و سیاست ذخیره‌سازی داده) و مدل محلی جایگزین.
- [ ] کدام سطح طبقه‌بندی اسناد مجاز به ارسال به LLM بیرونی است؟ آیا پنهان‌سازی اطلاعات حساس لازم است؟
- [ ] فهرست کامل فرمت‌های فایل مهندسی (غیر از AutoCAD) که در پیوست‌ها می‌آیند.
- [ ] نمونه‌ای از نامه‌های اسکن‌شده برای ارزیابی OCR فارسی.
- [ ] چه کسی (مثلاً واحد حقوقی) وضعیت اعتبار، اصلاح و نسخ مقررات را تأیید می‌کند؟
- [ ] فهرست دقیق کمیسیون‌های شهرداری و شورای شهر که مصوباتشان به سازمان قطار شهری مربوط است، و محل نگهداری صورت‌جلسات آن‌ها.
- [ ] الزامات امنیتی و طبقه‌بندی اطلاعات سازمان؛ آیا دستیار به نامه‌های محرمانه دسترسی دارد؟
- [ ] احراز هویت کاربران (Active Directory/LDAP؟).
- [ ] چند نفر و کدام دفاتر در فازهای بعد از دستیار استفاده می‌کنند؟
- [ ] سیاست نگهداری صوت جلسات (مدت، دسترسی).
- [ ] مالکیت کد و مجوز (با توجه به AGPL بودن Honcho).
- [ ] معیارهای پذیرش (Acceptance) برای پیمانکار: دقت STT، تأخیر، کیفیت استخراج مصوبات.
