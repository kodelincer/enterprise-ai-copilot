# سؤالات باز

## پاسخ داده شده

- [x] **آیا دستیار اجازه اقدام دارد؟** فاز ۱ خیر، فقط خواندن، تحلیل، یادگیری و پیشنهاد. ثبت و ارجاع وظیفه در فاز بعد. ([فازبندی](requirements/phasing.md))
- [x] **کجا اجرا شود؟** فعلاً هیچ‌جا؛ مرحله تحقیقات. در نهایت در دیتاسنتر سازمان توسط پیمانکار.
- [x] **وضعیت سامانه‌ها؟** برخی وب‌سرویس دارند، برخی فقط رابط کاربری؛ نیاز به Browser-use و ساخت MCP از تجربه. ([اتصال به سامانه‌ها](architecture/integration.md))

## باز

- [ ] فهرست دقیق سامانه‌های سازمان (دبیرخانه، نامه‌نگاری، CMMS، قراردادها، منابع انسانی، مالی، پروژه‌ها، انبار، تقویم) با نام نرم‌افزار، سازنده، نسخه، و نوع دسترسی (API، دیتابیس، فقط UI).
- [ ] تقویم سازمان روی چه بستری است؟
- [ ] موضوعات خلاصه خبری روزانه معاونت و منابع خبری مجاز.
- [ ] منابع سخت‌افزاری موجود در دیتاسنتر (GPU، سرور، ذخیره‌سازی) و بودجه خرید.
- [ ] انتخاب نهایی مدل زبانی (Qwen یا دیگر) پس از ارزیابی فارسی.
- [ ] الزامات امنیتی و طبقه‌بندی اطلاعات سازمان؛ آیا دستیار به نامه‌های محرمانه دسترسی دارد؟
- [ ] احراز هویت کاربران (Active Directory/LDAP؟).
- [ ] چند نفر و کدام دفاتر در فازهای بعد از دستیار استفاده می‌کنند؟
- [ ] سیاست نگهداری صوت جلسات (مدت، دسترسی).
- [ ] مالکیت کد و مجوز (با توجه به AGPL بودن Honcho).
- [ ] معیارهای پذیرش (Acceptance) برای پیمانکار: دقت STT، تأخیر، کیفیت استخراج مصوبات.
