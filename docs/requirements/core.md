# نیازمندی‌های اصلی

!!! warning "اولویت"
    موارد این صفحه طبق گفته کارفرما **«خیلی مهم»** هستند و هسته قرارداد را تشکیل می‌دهند.

## محل استقرار

یک دستیار هوشمند با **میکروفون** در **دفتر معاونت** (و در آینده دفاتر دیگر).

## فهرست نیازمندی‌ها

| شناسه | نیازمندی | توضیح |
|---|---|---|
| REQ-01 | ضبط جلسات | ضبط صدای جلسات حضوری دفتر معاونت |
| REQ-02 | تبدیل گفتار به متن فارسی | Speech-to-Text فارسی با **تشخیص گوینده** (Diarization) |
| REQ-03 | استخراج مصوبات و صورت‌جلسه | از دل متن، مصوبات و بندها استخراج و در صورت نیاز صورت‌جلسه تنظیم شود. صورت‌جلسه رسمی همیشه لازم نیست؛ مهم این است که دستیار گوش بدهد، داده داشته باشد و همکاری کند |
| REQ-04 | تعیین مسئول و پیگیری | برای هر بند مصوبه مشخص شود کدام مدیریت مسئول است و پیگیری‌ها انجام شود |
| REQ-05 | تقویم | تنظیم جلسات آینده در تقویم (در فاز ۱ به‌صورت پیشنهاد) |
| REQ-06 | خلاصه خبری روزانه | هر روز ساعت ۹ صبح، اخبار موضوعات مدنظر معاونت با **تحلیل** ارائه شود |
| REQ-07 | دبیرخانه و نامه‌نگاری | دسترسی به نامه‌ها **همراه با پیوست‌ها**؛ پردازش شبانه (Batch)؛ تحلیل نامه‌ها؛ باز کردن و خواندن **ارجاعات** نامه و تحلیل گردش آن |
| REQ-08 | یادگیری از مکاتبات | کسب دانش از نامه‌ها و **بخشنامه‌ها** و استفاده از آن در جلسات و تصمیم‌گیری‌ها |
| REQ-09 | اتصال به سامانه‌های سازمانی | نگهداری و تعمیرات (CMMS)، قراردادها، منابع انسانی و ساختار سازمانی، مالی، پروژه‌ها، انبار |
| REQ-10 | دستیار زنده جلسه | فهم هم‌زمان جلسه، پاسخ به درخواست صوتی/متنی، نمایش پیشنهاد با منبع روی مانیتور. جزئیات: [دستیار زنده جلسه](live-copilot.md) |
| REQ-11 | کار با سامانه‌های بدون API | سامانه‌های فاقد وب‌سرویس از طریق Browser-use؛ ساخت MCP اختصاصی از روی تجربه. جزئیات: [اتصال به سامانه‌ها](../architecture/integration.md) |
| REQ-12 | پیوست‌های متنوع | Word، Excel، PDF فارسی و انگلیسی، PDF اسکن‌شده فارسی (OCR)، RAR، AutoCAD و فایل‌های مهندسی. جزئیات: [پیوست‌ها](attachments.md) |
| REQ-13 | گسترش پذیری ابزارها | ابزارها و مهارت‌ها بر اساس نیازسنجی‌های بعدی اضافه شوند |
| REQ-14 | اتصال پویای منابع | اتصال به API یا زیرسیستم جدید در حین کار، خواندن و یادگیری داده آن. جزئیات: [اتصال منبع جدید](../architecture/integration.md#new-source) |
| REQ-15 | نگهداری داده در سازمان | همه دانش و داده On-Premises؛ فقط استدلال LLM می‌تواند وب‌سرویس بیرونی باشد. جزئیات: [نگهداری داده](../architecture/data-residency.md) |
| REQ-16 | دانش حقوقی و مقرراتی شهرداری | اساسنامه‌ها، قوانین، آیین‌نامه‌ها، مصوبات و بخشنامه‌های شورای شهر و کمیسیون‌ها، با فیلتر ارتباط با مترو با نسخه‌بندی، تاریخ اعتبار و ارجاع به ماده و بند. جزئیات: [دانش حقوقی](regulatory-knowledge.md) |
| REQ-17 | رابط ادمین مدیریت دانش | بارگذاری و مدیریت اسناد پایه (مثل اساسنامه سازمان‌ها و شرکت‌های وابسته) با فراداده، نسخه‌بندی، وضعیت اعتبار و کنترل دسترسی |

## سناریوی کاری نمونه

1. مدیران و معاونت در جلسه درباره موضوعی صحبت و تصمیم‌گیری می‌کنند و برای اجرا می‌روند.
2. دستیار گوش می‌دهد، متن را ثبت می‌کند، تصمیم‌ها و مسئولان را استخراج می‌کند.
3. در طول جلسه اگر از او سؤال شود، می‌رود جست‌وجو و تحلیل می‌کند و جواب می‌آورد.
4. اگر با توجه به دانشش نقطه‌نظری دارد، هم‌زمان روی مانیتور نشان می‌دهد.
5. بعد از جلسه پیگیری بندها را دنبال می‌کند (فاز ۱: پایش و یادآوری/گزارش؛ فاز بعد: ثبت و ارجاع).
