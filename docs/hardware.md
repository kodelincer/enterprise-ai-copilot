# زیرساخت و سخت‌افزار

!!! note "پیش‌نویس"
    مشخصات دقیق پس از تعیین مدل‌ها، تعداد کاربران و حجم داده نهایی می‌شود. در شرایط تحریم، تأمین‌پذیری هر قلم در ایران باید جداگانه بررسی شود.

## دفتر معاونت (اقلامی که باید خریداری شود)

| قلم | مشخصات پیشنهادی | دلیل |
|---|---|---|
| میکروفون جلسه | آرایه میکروفون سقفی یا رومیزی با Beamforming و حذف نویز/اکو؛ پوشش کل میز جلسه | کیفیت صدا مهم‌ترین عامل دقت STT و تشخیص گوینده است |
| رابط صوتی / پردازشگر | خروجی دیجیتال (USB یا Dante) به کامپیوتر محلی | انتقال صدای تمیز چندکاناله |
| نمایشگر | تلویزیون/مانیتور بزرگ (حدود ۶۵ تا ۷۵ اینچ) قابل دید از همه صندلی‌ها | نمایش متن زنده و پیشنهادهای دستیار |
| کامپیوتر محلی دفتر | Mini PC برای ضبط، ارسال صدا به سرور و نمایش رابط | نقطه اتصال دفتر به سکوی مرکزی |
| تبلت یا کیبورد بی‌سیم (اختیاری) | برای پرسیدن سؤال متنی از دستیار | |
| بلندگو (اختیاری) | اگر دستیار پاسخ صوتی بدهد | |

## دیتاسنتر سازمان

| مؤلفه | نیاز اولیه (تخمین، باید سنجیده شود) |
|---|---|
| سرور GPU برای LLM | **اختیاری**: چون استدلال LLM می‌تواند وب‌سرویس بیرونی باشد، GPU سنگین فقط برای مسیر جایگزین محلی لازم است |
| GPU برای Embedding و OCR | یک GPU متوسط برای Embedding محلی و OCR فارسی (به‌ویژه اگر از VLM استفاده شود) |
| GPU برای STT و Diarization | یک GPU متوسط برای پردازش زنده جلسه کافی است |
| سرور پایگاه داده | PostgreSQL + pgvector با SSD و پشتیبان‌گیری |
| ذخیره‌سازی | آرشیو صوت جلسات، اسناد و پیوست‌ها |
| شبکه | ارتباط امن دفتر معاونت با دیتاسنتر؛ دسترسی سرور به سامانه‌های داخلی |
| اینترنت کنترل‌شده | برای جمع‌آوری اخبار روزانه و فراخوانی سرویس LLM بیرونی، از طریق پراکسی کنترل‌شده با لاگ |

## ملاحظات

- **محرمانگی:** همه داده‌ها داخل سازمان ذخیره می‌شوند؛ فقط استدلال LLM می‌تواند بیرونی باشد ([نگهداری داده](architecture/data-residency.md)).
- **رضایت و اطلاع‌رسانی:** حاضران باید از ضبط جلسه مطلع باشند؛ نشانگر فیزیکی «در حال ضبط» توصیه می‌شود.
