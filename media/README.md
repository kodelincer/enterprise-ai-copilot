## ویرایش و رندر دوباره

1. متن‌ها را در `motion/index.html` تغییر دهید. باز کردن فایل در مرورگر پیش‌نمایش زنده پخش می‌کند.
2. `cd media/motion && node render.js out.mp4 30` (نیازمند Node، Playwright و ffmpeg).
3. موسیقی جداگانه با ffmpeg روی ویدیو اضافه شده است.
