# Enterprise AI Copilot — دستیار هوشمند سازمانی

مستند فنی و مخزن دانش پروژه دستیار هوشمند سازمانی برای دفتر معاونت. خروجی نهایی: مشخصات فنی برای تحویل به پیمانکار.

- محتوای مستند: پوشه [`docs/`](docs/index.md)
- اجرای محلی: `pip install -r requirements.txt && mkdocs serve`
- انتشار: با هر push روی `main`، GitHub Actions سایت را روی GitHub Pages منتشر می‌کند (Pages باید در Settings › Pages روی «GitHub Actions» تنظیم شود).

**قاعده:** هر مشخصه جدید یا هر یافته و تحلیل، در همین مخزن ثبت و push می‌شود و در [`docs/changelog.md`](docs/changelog.md) می‌آید.
